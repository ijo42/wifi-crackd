ИСТОЧНИК ДАННЫХ

USB‑адаптер

Встроенный Wi‑Fi телефона не используется. При запросе Android разрешите Termux:API доступ к USB.

Версия 0.4 · Один адаптер за сессию · Пассивный приём; активный deauth — только после согласия и только для WPA/WPA2‑PSK целей. Подбор паролей выполняет внешний Hashtopolis. Сканирование может продолжаться при сворачивании приложения, пока работает Termux.

Отключение интерфейса не останавливает приём. Для этого нажмите «Стоп».

ЗАХВАТЫ WPA/PMKID

Хеши hc22000

Крэкабельных хешей нет.

Хеши собираются из принятых хендшейков/PMKID. Скрытый SSID хеш не даёт. FT‑строки (802.11r) hashcat ‑m 22000 не брутит.

ВНЕШНИЙ БРУТ

Hashtopolis

Отправка хешей на ваш сервер Hashtopolis: hashlist (PLAIN, 22000) + цепочка задач из pretask'ов сервера. DEMO отправку блокирует.



Токен хранится только в приватном каталоге модуля (0600); пароль не сохраняется вовсе. Отправка передаёт SSID/BSSID/MAC внешнему серверу. Отправка блокируется, пока сессия не собрала ни одного хеша.
