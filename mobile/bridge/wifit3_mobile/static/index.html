Хеши собираются из принятых хендшейков/PMKID. Скрытый SSID хеш не даёт. FT‑строки (802.11r) hashcat ‑m 22000 не брутит.


ВНЕШНИЙ БРУТ
Hashtopolis


Отправка хешей на ваш сервер Hashtopolis: hashlist (PLAIN, 22000) + цепочка задач из pretask'ов сервера. DEMO отправку блокирует.














Токен хранится только в приватном каталоге модуля (0600); пароль не сохраняется вовсе. Отправка передаёт SSID/BSSID/MAC внешнему серверу.

    Состояние модуля
      

      

      ОСНОВНОЙ РЕЖИМ · USB
      USB‑адаптер в Termux
      Встроенный Wi‑Fi телефона не используется. При запросе Android разрешите Termux:API доступ к USB. «Демо» — диагностический режим без радио, выбирается при запуске модуля.
      




      Версия 0.4 · Один адаптер за сессию · Пассивный приём; активный deauth — только после согласия и только для WPA/WPA2‑PSK целей. Подбор паролей выполняет внешний Hashtopolis. Приём продолжается при сворачивании приложения, пока работает Termux.
      


      Аналог Ctrl+C: останавливает deauth/приём, освобождает USB и закрывает локальный сервер. Для управляемого режима есть также кнопка «Стоп модуль» в Termux‑панели и команда wifit3‑mobile‑service stop.
      

      Отключение интерфейса не останавливает приём. Для этого нажмите «Стоп» или «Завершить модуль».
